# Persona – John Plum

- **Name:** John Plum
- **Age:** 21
- **Occupation:** University student
- **Location:** Perth, Western Australia

**Goals:**
- Access educational material independently.
- Read and understand study documents using assistive technology.
- Organise study materials and locate documents easily.
- Complete assignments without unnecessary difficulty.

**Frustrations:**
- Applications that are not compatible with screen readers.
- Interfaces that require mouse interaction.
- Buttons and controls without clear accessible labels.
- Important information communicated only through images, colours or visual elements.
- Poorly structured documents that are difficult to navigate using a screen reader.

**Motivations:**
- Become more independent with studying.
- Improve productivity.
- Access educational resources without relying on others.
- Use technology to overcome accessibility barriers.

**Technology:**
- Windows desktop computer.
- Smartphone.
- Microsoft Office.
- Web browsers and educational platforms.
- Screen-reading software, such as NVDA.

**Experience:**

Comfortable using computers and everyday software, including keyboard-based navigation and assistive technology. However, some applications present accessibility barriers when their interfaces are not designed for screen readers.

**Personality:** Independent, curious, patient and motivated to learn.

**Interests:** Technology, gaming, programming and digital media.
